어떤 데이터를 사용하는지

운영자가 Google 계정에서 접근을 허용하면, 오피스는 Google Ads 계정 ID와 OAuth 인증 토큰을 사용합니다. 키워드 조사에는 검색어, 대상 국가·언어, 관련 키워드와 월평균 검색량을 사용합니다. Google 계정 비밀번호는 Google의 로그인 화면에서 처리합니다.

데이터를 사용하는 목적

오피스는 Google Ads API로 시장 조사와 콘텐츠 기획에 필요한 키워드 데이터를 읽습니다. 확인한 수치는 상품과 독자 선정, 제목 검토, 운영자 보고에 사용합니다. 현재 연결 기능의 API 요청 범위는 키워드 조회입니다.

저장 및 전송

연결을 유지하는 인증 정보는 오피스가 실행되는 기기의 접근이 제한된 설정 파일에 저장합니다. 작업별 조회 시각, 검색어, 조회 결과는 해당 오피스의 업무 기록에 남습니다.

인증 정보는 Google 인증과 Google Ads API 요청에 사용합니다. 조사 및 보고 업무에는 운영자가 연결한 AI 서비스에 필요한 검색어와 조회 결과를 전달할 수 있습니다. 이 정보는 사용자가 오피스에서 요청한 업무를 수행하는 데 사용합니다.

Google API에서 받은 데이터의 이용과 전달에는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다. Google API 서비스 사용자 데이터 정책
